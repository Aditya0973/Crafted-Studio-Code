# Crafted Studio Vision & Roadmap

## Product Vision

Crafted Studio is **not another AI IDE**. It is an **AI Software
Development Operating System** that guides users from idea to deployment
while also providing a professional development workspace.

## Two Core Layers

### Layer 1 --- Workspace Foundation

-   Explorer
-   File & Folder Operations
-   Monaco Code Editor
-   Markdown Editor
-   Syntax Highlighting
-   Tabs & Split Views
-   Integrated Terminal
-   Settings
-   Tool Dock
-   AI Providers

### Layer 2 --- AI Operating System

-   Beginner Onboarding
-   Guided Workflow
-   Project Documents
-   AI Discussions
-   Prompt Generation
-   Stitch Integration
-   Antigravity Integration
-   Deployment Workflow
-   Project Memory

## Development Principles

1.  Foundation before advanced AI.
2.  Beginner-friendly by default.
3.  Advanced mode for experienced developers.
4.  AI assists; users remain in control.
5.  Never modify project files without review.
6.  Removing a project never deletes user files.
7.  Workflow actions should ultimately operate on real project
    documents.
